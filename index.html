How to use

  1. Dashboard: set your plan start date (and optional exam date). All plan dates follow it.
  2. Status: change it in the Topic Tracker dropdown. Topics 1–55 start as Watched; 56–74 as Not started.
  3. Ratings: rate Understanding and Exam readiness 1–5 using the guide on the Dashboard. Be honest.
  4. Last studied: pick a date. Next review is suggested automatically: +1 day for ratings 1–2, +3 days for 3, +7 days for 4–5. It stays blank until both date and understanding are set, and turns red when due.
  5. Notes: type in the Notes box; it saves as you type. Use the search and filters above the table to find topics.
  6. 30-Day Plan: set each day to No / In progress / Yes and add results.
  7. Saving: everything saves automatically in this browser on this computer. Use the same browser and don't clear site data. Progress doesn't sync between browsers or devices.
  8. Lesson links: built from each topic title in the CBT Nuggets URL format. If one doesn't open, search for the topic inside the course.
